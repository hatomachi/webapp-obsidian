# 🎙️ Obsidian 議事録（Minutes）ビューア 機能・フォーマット完全仕様ガイド（AI・開発者向け）

本ドキュメントは、AIエージェント（ChatGPT, Claude, Gemini, Cursor等）およびユーザーが、**Web App Obsidian (webapp-obsidian) の 議事録（Minutes）ビューア機能** で表示・再生・編集するための `.minutes` / `.minutesv` 定義ファイルや、会議フォルダ（音声・Whisper文字起こし・スクショ画像・議事録Markdown）を正しく作成・配置するための完全仕様書です。

---

## 1. 🎯 議事録（Minutes）ビューアの概要

会議の **「音声（mp3/m4a）」「Whisper文字起こし（yaml）」「タイムスタンプ付き会議スクリーンショット（jpeg/png）」「生成された議事録（md）」** を1つのリッチなUIで一元管理し、同期再生・シーク・タイムスタンプジャンプ・直接編集を可能にする完全疎結合ビューアです。

### 主な特徴
1. **0秒起動・完全サーバーレス**: Cloudflare Pages 上で直接動作し、ブラウザから Git リポジトリ（GitHub / 社内GitLab）へ直接通信。
2. **音声プレイヤーとタイムライン完全同期**:
   - シークバー、巻き戻し（-5秒）、早送り（+10秒）、再生速度変更（0.75x〜2.0x）。
   - 音声再生に合わせて文字起こしがハイライトされ、自動スクロール追従（ON/OFF可能）。
3. **タイムスタンプからの即時シークジャンプ**:
   - 文字起こしのタイムスタンプ（`[05:12]` 等）をタップすると、音声プレイヤーがその時間へ即座にシーク。
   - スライド画像をクリックするとLightbox拡大表示＆その時間へのジャンプが可能。
4. **議事録（Markdown）の閲覧・直接編集 ＆ Git自動コミット**:
   - タブ切り替え（タイムライン / 議事録 / 画面分割）に対応。
   - 議事録Markdownを直接エディタで修正し、ワンタップ（または `Ctrl+Enter`）で裏側Gitへ安全にコミット保存。
   - 議事録編集中に「現在再生位置のタイムスタンプ挿入（`+ [05:12]`）」ボタンを完備。
5. **複数会議のワンタップ切替**:
   - 親フォルダを指定すると、配下の過去・最新の会議フォルダ群を自動検出し、日付順でプルダウンから即座に切り替え可能。

## 2. 🗂️ 推奨ファイル拡張子（センスと柔軟性）

Obsidianの `.base` に並び、議事録用として以下の拡張子を自動認識します：

| 拡張子 | 説明・用途 |
| :--- | :--- |
| **`.minutes`** | **【推奨】** 最もシンプルでスマート。Obsidianライクな設計。 |
| **`.minutesv`** | Minutes Viewerの略称。明示的なビューア指定。 |
| **`.minute`** | 単数形表記。 |
| **`.minutes.yaml` / `.minutes.yml`** | 通常のエディタでYAMLとしてシンタックスハイライトを効かせたい場合。 |
| **`.minutes.md`** | フロントマターに `type: minutes` を書く場合。 |

## 3. 📂 フォルダ構成とファイル配置の完全ルール

### ① 会議親フォルダを指定する場合（複数会議の管理・最も推奨）

```text
vault-root/
├── 20_Meetings.minutes              # 議事録ビューア定義ファイル
└── 20_Meetings/                     # 会議格納先フォルダ
    ├── 2026-09-24_開発定例/         # 各会議のフォルダ（日付_会議名）
    │   ├── audio.mp3                # 音声ファイル (.mp3, .m4a, .wav 等)
    │   ├── transcript.yaml          # Whisper文字起こしYAML
    │   ├── 00_05_12_スライド.jpeg   # タイムスタンプ付き会議スクショ
    │   ├── 00_15_30_アーキ図.jpg
    │   └── minutes.md               # 議事録Markdown
    └── 2026-09-17_キックオフ/
        ├── recording.m4a
        ├── whisper.yaml
        ├── 00_02_10_自己紹介.png
        └── 議事録.md
```

#### 定義ファイル例（`20_Meetings.minutes`）
```yaml
target: 20_Meetings
title: 開発定例・ミーティング一覧
defaultSpeed: 1.25
```

---

### ② 単一会議フォルダを直接指定する場合

特定の会議1つだけを直接ビューアとして登録したい場合：

#### 定義ファイル例（`2026-09-24_定例.minutes`）
```yaml
target: 20_Meetings/2026-09-24_開発定例
title: 2026-09-24 第12回 開発定例会議
```

## 4. 📝 各ファイルフォーマット仕様

### 1. 音声ファイル（Audio）
- **対応拡張子**: `.mp3`, `.m4a`, `.wav`, `.ogg`, `.webm`, `.aac`
- **自動検出**: フォルダ直下の音声ファイルを自動認識します（明示的に `audio: custom.mp3` と定義ファイルに指定することも可能）。

### 2. Whisper文字起こしファイル（Transcript YAML）
- **対応拡張子**: `.yaml`, `.yml`（または `.json`）
- **ファイル名**: `transcript.yaml`, `transcription.yaml`, `whisper.yaml`, またはフォルダ内の `.yaml`
- **サポートするフォーマット**: 以下のいずれの形式でも自動パースされます。

#### パターンA：標準リスト形式（Whisper出力で最も一般的・推奨）
```yaml
- start: 0.0
  end: 4.5
  speaker: 佐藤
  text: 本日はお集まりいただきありがとうございます。
- start: 4.8
  end: 9.2
  speaker: 田中
  text: それでは今週の開発進捗の確認から始めましょう。
- start: 10.0
  text: スライドを画面共有します。
```

#### パターンB：Whisper JSON出力をYAML変換した形式
```yaml
segments:
  - id: 0
    start: 0.0
    end: 4.5
    text: 本日はお集まりいただきありがとうございます。
  - id: 1
    start: 4.8
    end: 9.2
    text: それでは今週の開発進捗の確認から始めましょう。
```

#### パターンC：タイムスタンプ文字列キー形式
```yaml
"00:00": 本日はお集まりいただきありがとうございます。
"00:05": それでは今週の開発進捗の確認から始めましょう。
"01:23": アーキテクチャの変更点について説明します。
```

---

### 3. 会議スクリーンショット画像（Screenshots）
- **対応拡張子**: `.jpg`, `.jpeg`, `.png`, `.webp`
- **ファイル名のタイムスタンプ命名規則**:
  ファイル名に含まれる時刻表記から、自動的に該当秒数を抽出してタイムライン上に同期配置します。

| ファイル名の例 | 認識される時間 | 該当秒数 |
| :--- | :--- | :--- |
| `00_05_12_screen.jpeg` / `00:05:12.png` / `00-05-12.jpg` | `05:12` (5分12秒) | 312秒 |
| `01_23_45_slide.jpg` | `01:23:45` (1時間23分45秒) | 5025秒 |
| `05_12.jpg` / `05-12.png` | `05:12` (5分12秒) | 312秒 |
| `120s.png` / `300sec.jpeg` | `02:00` (120秒) | 120秒 |
| `312.jpeg` (数字のみ) | `05:12` (312秒) | 312秒 |

---

### 4. 議事録Markdownファイル（Minutes Markdown）
- **対応拡張子**: `.md`, `.markdown`
- **ファイル名**: `minutes.md`, `議事録.md`, `README.md`, `notes.md`, またはフォルダ内の `.md`
- **機能**:
  - GFMテーブル、チェックボックス、Callout、WikiLinkをリッチ表示。
  - **直接編集**: 右上の「✏️ 議事録を編集」からインラインTextareaで直接Markdownを書き換え、`Ctrl+Enter` または「保存」ボタンでGitへ即座に自動コミット。
  - **タイムスタンプ挿入**: 編集中、ヘッダーの「+ [05:12]」ボタンを押すと、再生中のタイムスタンプがカーソル位置に自動挿入されます。

## 5. 🛠️ `.minutes` 設定ファイルの全プロパティ一覧

```yaml
# 会議フォルダのパス（必須）
target: 20_Meetings

# ビューアのタイトル（任意）
title: プロジェクト全体議事録

# ファイル名の個別明示指定（自動検出を上書きしたい場合のみ）
# audio: meeting_record.mp3
# transcript: whisper_result.yaml
# minutes: summary.md

# デフォルト再生速度（任意、デフォルト 1.0）
defaultSpeed: 1.25

# スクリーンショットをタイムラインに表示するか（任意、デフォルト true）
showScreenshots: true
```
